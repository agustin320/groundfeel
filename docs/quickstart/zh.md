# URSA Rumble — 快速入门

[English](en.md)

在 Microsoft Flight Simulator 2024 中为 WinWing (WINCTRL) URSA MINOR 32 摇杆和油门提供逼真的振动。免费且开源。

## 1. 安装

1. 从[最新版本](https://github.com/agustin320/vibracion-ursa/releases/latest)下载 `VibracionURSA-Setup.exe`。
2. 运行它。它只为当前用户安装，不需要管理员权限。
3. 如果 Windows SmartScreen 提示发布者未知，请点击 **更多信息 → 仍要运行**。本程序目前还没有代码签名。
4. 保持勾选 **开机时启动**（安装程序中显示为 Start with Windows）。它会在系统托盘中等待，直到你打开模拟器。

## 2. 首次使用

1. 在 **SimAppPro** 中关闭摇杆和油门的振动。否则两个程序会争抢电机。
2. 打开模拟器。托盘图标（在时钟旁边）连接成功时显示 **绿点**，等待时显示 **灰色**，暂停时显示 **橙色**。

## 3. 设置

右键点击托盘图标 → **设置**：

- **状态：** 与模拟器的连接、找到的设备，以及当前正在振动的效果。
- **强度：** 摇杆、油门和地面滑行的振动强度。
- **选项：** 摇杆仅在地面振动、暂停振动、开机时启动、语言。
- **更新：** 已安装版本、**立即检查**、**立即更新**、自动检查并安装更新。

更改会立即生效。

## 4. 更新

新版本会在你关闭模拟器时自动安装，绝不会在飞行途中进行。更新完成后会有通知提醒你。你可以在“设置”中关闭此功能。

## 5. 遇到问题？

- 右键点击托盘图标 → **报告问题…**。它会打开一个预先填好的 GitHub issue，其中你的用户名和计算机名已被隐藏。除非你主动提交，否则不会发送任何内容。

没有遥测，不收集个人数据。唯一的联网操作是连接 GitHub 检查和下载更新，你可以在“设置”中关闭它。
