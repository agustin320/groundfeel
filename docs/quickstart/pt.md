# URSA Rumble — Guia rápido

[English](en.md)

Vibração realista para o joystick e o manete WinWing (WINCTRL) URSA MINOR 32 no Microsoft Flight Simulator 2024. Gratuito e de código aberto.

## 1. Instalação

1. Baixe o `VibracionURSA-Setup.exe` da [versão mais recente](https://github.com/agustin320/vibracion-ursa/releases/latest).
2. Execute. Ele é instalado só para o seu usuário, sem permissão de administrador.
3. Se o Windows SmartScreen disser que o editor é desconhecido, clique em **Mais informações → Executar assim mesmo**. O programa ainda não tem assinatura digital.
4. Deixe marcada a opção **Iniciar com o Windows** (no instalador aparece como "Start with Windows"). Ele fica esperando na bandeja do sistema até você abrir o simulador.

## 2. Primeiro uso

1. No **SimAppPro**, desative a vibração do joystick e do manete. Caso contrário, os dois programas brigam pelos motores.
2. Abra o simulador. O ícone na bandeja (ao lado do relógio) mostra um **ponto verde** quando está conectado, **cinza** enquanto espera e **laranja** quando está pausado.

## 3. Configurações

Clique com o botão direito no ícone da bandeja → **Configurações**:

- **Status:** conexão com o simulador, dispositivos encontrados e o que está vibrando agora.
- **Intensidade:** força do joystick, do manete e da rolagem no solo.
- **Opções:** joystick vibra apenas no solo, pausar a vibração, iniciar com o Windows, idioma.
- **Atualizações:** versão instalada, **Verificar agora**, **Atualizar agora** e atualizações automáticas.

As alterações valem na hora.

## 4. Atualizações

As novas versões se instalam sozinhas quando você fecha o simulador, nunca no meio do voo. Uma notificação avisa quando houve atualização. Você pode desativar isso nas Configurações.

## 5. Problemas?

- Clique com o botão direito no ícone da bandeja → **Relatar um problema…**. Isso abre uma issue no GitHub já preenchida, com seu nome de usuário e o nome do computador ocultos. Nada é enviado a menos que você envie.

## Privacidade

Sem telemetria e sem dados pessoais. A única conexão com a internet é com o GitHub, para procurar e baixar atualizações, e você pode desativá-la nas Configurações.
