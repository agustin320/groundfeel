# Groundfeel — فوری آغاز

[English](en.md)

Microsoft Flight Simulator 2024 میں WinWing (WINCTRL) URSA MINOR 32 جوائس اسٹک اور تھروٹل کے لیے حقیقت کے قریب وائبریشن۔ مفت اور اوپن سورس۔

## 1. انسٹال کریں

1. [تازہ ترین ریلیز](https://github.com/agustin320/vibracion-ursa/releases/latest) سے `VibracionURSA-Setup.exe` ڈاؤن لوڈ کریں۔
2. اسے چلائیں۔ یہ صرف آپ کے یوزر کے لیے انسٹال ہوتا ہے، ایڈمن اختیارات کی ضرورت نہیں۔
3. اگر Windows SmartScreen کہے کہ پبلشر نامعلوم ہے تو (**More info → Run anyway**) پر کلک کریں۔ پروگرام پر ابھی ڈیجیٹل دستخط نہیں ہیں۔
4. **Windows کے ساتھ شروع کریں** کو منتخب رہنے دیں۔ سمیلیٹر کھلنے تک یہ نوٹیفکیشن ایریا میں انتظار کرتا ہے۔

## 2. پہلی بار استعمال

1. **SimAppPro** میں جوائس اسٹک اور تھروٹل کی وائبریشن بند کر دیں۔ ورنہ دونوں پروگرام موٹرز پر آپس میں الجھیں گے۔
2. سمیلیٹر کھولیں۔ نوٹیفکیشن ایریا (گھڑی کے ساتھ) والا آئیکن کنکشن ہونے پر **سبز نقطہ**، انتظار کے دوران **سرمئی** اور وقفے میں **نارنجی** دکھاتا ہے۔

## 3. ترتیبات

نوٹیفکیشن ایریا کے آئیکن پر رائٹ کلک کریں ← **ترتیبات**:

- **حالت:** سمیلیٹر سے کنکشن، ملنے والے آلات اور اس وقت کیا وائبریٹ ہو رہا ہے۔
- **شدت:** جوائس اسٹک، تھروٹل اور زمینی رولنگ کی طاقت۔
- **اختیارات:** جوائس اسٹک صرف زمین پر، وقفہ، Windows کے ساتھ شروع کریں، زبان۔
- **اپ ڈیٹس:** انسٹال شدہ ورژن، "ابھی چیک کریں"، "ابھی اپ ڈیٹ کریں"، خودکار اپ ڈیٹس۔

تبدیلیاں فوراً لاگو ہو جاتی ہیں۔

## 4. اپ ڈیٹس

نئے ورژن سمیلیٹر بند کرنے پر خود بخود انسٹال ہو جاتے ہیں، پرواز کے دوران کبھی نہیں۔ اپ ڈیٹ ہونے پر ایک نوٹیفکیشن آپ کو بتا دیتا ہے۔ آپ اسے ترتیبات میں بند کر سکتے ہیں۔

## 5. کوئی مسئلہ؟

- نوٹیفکیشن ایریا کے آئیکن پر رائٹ کلک کریں ← **مسئلے کی اطلاع دیں…**۔ یہ GitHub پر پہلے سے بھرا ہوا ایک issue کھولتا ہے جس میں آپ کا یوزر نیم اور کمپیوٹر کا نام چھپا ہوتا ہے۔ جب تک آپ خود اسے جمع نہ کرائیں، کچھ نہیں بھیجا جاتا۔
