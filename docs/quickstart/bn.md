# Groundfeel — দ্রুত শুরু

[English](en.md)

Microsoft Flight Simulator 2024-এ WinWing (WINCTRL) URSA MINOR 32 জয়স্টিক ও থ্রটলের জন্য বাস্তবসম্মত কম্পন। বিনামূল্যে এবং ওপেন সোর্স।

## 1. ইনস্টল

1. [সর্বশেষ রিলিজ](https://github.com/agustin320/vibracion-ursa/releases/latest) থেকে `VibracionURSA-Setup.exe` ডাউনলোড করুন।
2. এটি চালান। এটি শুধু আপনার ব্যবহারকারীর জন্য ইনস্টল হয়, অ্যাডমিন অনুমতি ছাড়াই।
3. Windows SmartScreen যদি বলে প্রকাশক অজানা, তাহলে "আরও তথ্য" এবং তারপর "তবুও চালান"-এ ক্লিক করুন (**More info → Run anyway**)। প্রোগ্রামটিতে এখনও কোড সাইনিং নেই।
4. **Windows-এর সাথে চালু করুন** (ইনস্টলারে "Start with Windows") টিক দেওয়া রাখুন। আপনি সিমুলেটর না খোলা পর্যন্ত এটি সিস্টেম ট্রেতে অপেক্ষা করে।

## 2. প্রথম ব্যবহার

1. **SimAppPro**-তে জয়স্টিক ও থ্রটলের কম্পন বন্ধ করুন। নাহলে দুটি প্রোগ্রাম মোটর নিয়ে টানাটানি করবে।
2. সিমুলেটর খুলুন। ট্রে আইকন (ঘড়ির পাশে) সংযুক্ত হলে **সবুজ বিন্দু**, অপেক্ষার সময় **ধূসর** এবং বিরতিতে **কমলা** দেখায়।

## 3. সেটিংস

ট্রে আইকনে রাইট-ক্লিক করুন → **সেটিংস**:

- **অবস্থা:** সিমুলেটরের সাথে সংযোগ, খুঁজে পাওয়া ডিভাইস এবং এই মুহূর্তে কী কাঁপছে।
- **তীব্রতা:** জয়স্টিক, থ্রটল ও গ্রাউন্ড রোলের শক্তি।
- **বিকল্প:** জয়স্টিক শুধু মাটিতে কাঁপবে, কম্পন বিরতি, Windows-এর সাথে চালু করুন, ভাষা।
- **আপডেট:** ইনস্টল করা সংস্করণ, **এখনই খুঁজুন**, **এখনই আপডেট করুন**, স্বয়ংক্রিয় আপডেট।

পরিবর্তন সঙ্গে সঙ্গে কার্যকর হয়।

## 4. আপডেট

নতুন সংস্করণ সিমুলেটর বন্ধ করলে নিজে থেকেই ইনস্টল হয়, কখনও উড্ডয়নের মাঝখানে নয়। আপডেট হলে একটি বিজ্ঞপ্তি আপনাকে জানায়। আপনি সেটিংসে এটি বন্ধ করতে পারেন।

## 5. সমস্যা?

- ট্রে আইকনে রাইট-ক্লিক করুন → **সমস্যা জানান…**। এটি আগে থেকে পূরণ করা একটি GitHub issue খোলে, যেখানে আপনার ব্যবহারকারীর নাম ও কম্পিউটারের নাম লুকানো থাকে। আপনি জমা না দিলে কিছুই পাঠানো হয় না।
