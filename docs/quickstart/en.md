# Groundfeel — Quick start

Realistic vibration for the WinWing (WINCTRL) URSA MINOR 32 joystick and throttle in Microsoft Flight Simulator 2024. Free and open source.

## 1. Install

1. Download `VibracionURSA-Setup.exe` from the [latest release](https://github.com/agustin320/vibracion-ursa/releases/latest).
2. Run it. It installs for your user only, without admin rights.
3. If Windows SmartScreen says the publisher is unknown, click **More info → Run anyway**. The program isn't code-signed yet.
4. Keep **Start with Windows** ticked. It waits in the tray until you open the simulator.

## 2. First use

1. In **SimAppPro**, turn off the vibration for the joystick and the throttle. Otherwise both programs fight over the motors.
2. Open the simulator. The tray icon (next to the clock) shows a **green dot** when it's connected, **gray** while waiting and **orange** when paused.

## 3. Settings

Right-click the tray icon → **Settings**:

- **Status:** simulator connection, devices found and what is vibrating right now.
- **Intensity:** joystick, throttle and ground roll strength.
- **Options:** joystick on the ground only, pause, start with Windows, language.
- **Updates:** installed version, check now, update now, automatic updates.

Changes apply instantly.

## 4. Updates

New versions install by themselves when you close the simulator, never mid-flight. A notification tells you when it updated. You can turn this off in Settings.

## 5. Problems?

- Right-click the tray icon → **Report a problem…**. It opens a pre-filled GitHub issue with your user name and computer name masked. Nothing is sent unless you submit it.
- Full guide: [English](../USER_GUIDE.md) · [Español](../GUIA_DE_USUARIO.md)

## Privacy

No telemetry and no personal data. The only internet connection is to GitHub to check for and download updates, and you can turn it off in Settings.
