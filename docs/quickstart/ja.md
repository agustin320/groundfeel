# URSA Rumble — クイックスタート

[English](en.md)

Microsoft Flight Simulator 2024 で WinWing (WINCTRL) URSA MINOR 32 のジョイスティックとスロットルにリアルな振動を加えます。無料のオープンソースです。

## 1. インストール

1. [最新リリース](https://github.com/agustin320/vibracion-ursa/releases/latest)から `VibracionURSA-Setup.exe` をダウンロードします。
2. 実行します。管理者権限なしで、現在のユーザーだけにインストールされます。
3. Windows SmartScreen に発行元が不明と表示された場合は、**詳細情報 → 実行** をクリックします。このプログラムはまだコード署名されていません。
4. **Windows と同時に起動** はオンのままにしておきます。シミュレーターを起動するまで通知領域で待機します。

## 2. 初めて使うとき

1. **SimAppPro** で、ジョイスティックとスロットルの振動をオフにします。オフにしないと、両方のプログラムがモーターを奪い合います。
2. シミュレーターを起動します。通知領域（時計の横）のアイコンは、接続中は **緑の点**、待機中は **灰色**、一時停止中は **オレンジ** になります。

## 3. 設定

通知領域のアイコンを右クリック → **設定**：

- **状態：** シミュレーターとの接続、検出されたデバイス、いま振動しているもの。
- **強さ：** ジョイスティック、スロットル、地上走行の振動の強さ。
- **オプション：** ジョイスティックは地上でのみ振動、一時停止、Windows と同時に起動、言語。
- **更新：** インストール済みバージョン、「今すぐ確認」、「今すぐ更新」、自動更新。

変更はすぐに反映されます。

## 4. 更新

新しいバージョンは、シミュレーターを閉じたときに自動でインストールされます。飛行中に更新されることはありません。更新されると通知でお知らせします。この機能は設定でオフにできます。

## 5. 問題がありますか？

- 通知領域のアイコンを右クリック → **問題を報告…**。ユーザー名とコンピューター名を伏せた状態で、入力済みの GitHub issue が開きます。あなたが送信しない限り、何も送られません。
