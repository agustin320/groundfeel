# Groundfeel — 빠른 시작

[English](en.md)

Microsoft Flight Simulator 2024에서 WinWing (WINCTRL) URSA MINOR 32 조이스틱과 스로틀에 사실적인 진동을 제공합니다. 무료 오픈 소스입니다.

## 1. 설치

1. [최신 릴리스](https://github.com/agustin320/vibracion-ursa/releases/latest)에서 `VibracionURSA-Setup.exe`를 다운로드합니다.
2. 실행합니다. 관리자 권한 없이 현재 사용자에게만 설치됩니다.
3. Windows SmartScreen에서 게시자를 알 수 없다고 표시되면 **추가 정보 → 실행**을 클릭합니다. 이 프로그램은 아직 코드 서명이 되어 있지 않습니다.
4. **Windows 시작 시 실행**을 체크한 상태로 두세요. 시뮬레이터를 열 때까지 알림 영역에서 대기합니다.

## 2. 처음 사용하기

1. **SimAppPro**에서 조이스틱과 스로틀의 진동을 끕니다. 그렇지 않으면 두 프로그램이 모터를 두고 충돌합니다.
2. 시뮬레이터를 엽니다. 알림 영역 아이콘(시계 옆)은 연결되면 **초록색 점**, 대기 중에는 **회색**, 일시 중지 중에는 **주황색**으로 표시됩니다.

## 3. 설정

알림 영역 아이콘을 마우스 오른쪽 버튼으로 클릭 → **설정**:

- **상태:** 시뮬레이터 연결, 감지된 장치, 지금 진동 중인 항목.
- **강도:** 조이스틱, 스로틀, 지상 주행 진동의 세기.
- **옵션:** 조이스틱은 지상에서만 진동, 일시 중지, Windows 시작 시 실행, 언어.
- **업데이트:** 설치된 버전, 지금 확인, 지금 업데이트, 자동 업데이트.

변경 사항은 즉시 적용됩니다.

## 4. 업데이트

새 버전은 비행 중이 아니라 시뮬레이터를 닫을 때 자동으로 설치됩니다. 업데이트되면 알림으로 알려 드립니다. 설정에서 이 기능을 끌 수 있습니다.

## 5. 문제가 있나요?
