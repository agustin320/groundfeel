# URSA Rumble — झटपट सुरुवात

[English](en.md)

Microsoft Flight Simulator 2024 मध्ये WinWing (WINCTRL) URSA MINOR 32 जॉयस्टिक आणि थ्रॉटलसाठी वास्तववादी कंपन. मोफत आणि ओपन सोर्स.

## 1. इन्स्टॉल करा

1. [नवीनतम रिलीज](https://github.com/agustin320/vibracion-ursa/releases/latest) मधून `VibracionURSA-Setup.exe` डाउनलोड करा.
2. ते चालवा. ते फक्त तुमच्या युजरसाठी इन्स्टॉल होते, ॲडमिन अधिकारांशिवाय.
3. Windows SmartScreen प्रकाशक अज्ञात असल्याचे सांगत असल्यास (**More info → Run anyway**) वर क्लिक करा. प्रोग्रामवर अजून डिजिटल स्वाक्षरी नाही.
4. **Windows सोबत सुरू करा** टिक केलेले ठेवा. तुम्ही सिम्युलेटर उघडेपर्यंत ते नोटिफिकेशन एरियामध्ये वाट पाहते.

## 2. पहिला वापर

1. **SimAppPro** मध्ये जॉयस्टिक आणि थ्रॉटलचे कंपन बंद करा. नाहीतर दोन्ही प्रोग्राम मोटर्ससाठी एकमेकांशी भांडतील.
2. सिम्युलेटर उघडा. नोटिफिकेशन एरियातील (घड्याळाशेजारी) आयकॉन कनेक्ट झाल्यावर **हिरवा ठिपका**, वाट पाहताना **राखाडी** आणि थांबवलेले असताना **नारिंगी** दाखवतो.

## 3. सेटिंग्ज

नोटिफिकेशन एरियातील आयकॉनवर राइट-क्लिक करा → **सेटिंग्ज**:

- **स्थिती:** सिम्युलेटरशी कनेक्शन, सापडलेली उपकरणे आणि आत्ता काय कंपन करत आहे.
- **तीव्रता:** जॉयस्टिक, थ्रॉटल आणि ग्राउंड रोलची ताकद.
- **पर्याय:** जॉयस्टिक फक्त जमिनीवर, थांबवा, Windows सोबत सुरू करा, भाषा.
- **अपडेट:** इन्स्टॉल केलेली आवृत्ती, "आता तपासा", "आता अपडेट करा", आपोआप अपडेट.

बदल लगेच लागू होतात.

## 4. अपडेट

तुम्ही सिम्युलेटर बंद केल्यावर नवीन आवृत्त्या आपोआप इन्स्टॉल होतात, उड्डाणादरम्यान कधीच नाही. अपडेट झाल्यावर एक सूचना तुम्हाला कळवते. तुम्ही हे सेटिंग्जमध्ये बंद करू शकता.

## 5. काही समस्या?

- नोटिफिकेशन एरियातील आयकॉनवर राइट-क्लिक करा → **समस्या कळवा…**. यामुळे GitHub वर आधीच भरलेला एक issue उघडतो, ज्यात तुमचे युजर नाव आणि संगणकाचे नाव लपवलेले असते. तुम्ही स्वतः सबमिट केल्याशिवाय काहीही पाठवले जात नाही.
