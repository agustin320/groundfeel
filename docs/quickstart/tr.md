# URSA Rumble — Hızlı başlangıç

[English](en.md)

Microsoft Flight Simulator 2024'te WinWing (WINCTRL) URSA MINOR 32 joystick ve gaz kolu için gerçekçi titreşim. Ücretsiz ve açık kaynak.

## 1. Kurulum

1. `VibracionURSA-Setup.exe` dosyasını [son sürümden](https://github.com/agustin320/vibracion-ursa/releases/latest) indirin.
2. Çalıştırın. Yönetici hakları gerekmeden yalnızca sizin kullanıcınız için kurulur.
3. Windows SmartScreen yayımcının bilinmediğini söylerse **Ek bilgi** (More info) → **Yine de çalıştır** (Run anyway) seçeneğine tıklayın. Programın henüz kod imzası yok.
4. **Windows ile başlat** seçeneğini işaretli bırakın. Simülatörü açana kadar bildirim alanında bekler.

## 2. İlk kullanım

1. **SimAppPro**'da joystick ve gaz kolu titreşimini kapatın. Aksi takdirde iki program motorlar için çakışır.
2. Simülatörü açın. Bildirim alanındaki simge (saatin yanında) bağlıyken **yeşil nokta**, beklerken **gri**, duraklatıldığında **turuncu** gösterir.

## 3. Ayarlar

Bildirim alanındaki simgeye sağ tıklayın → **Ayarlar**:

- **Durum:** simülatör bağlantısı, bulunan cihazlar ve şu anda neyin titreştiği.
- **Yoğunluk:** joystick, gaz kolu ve yer hareketi titreşiminin gücü.
- **Seçenekler:** joystick yalnızca yerde, duraklatma, Windows ile başlat, dil.
- **Güncellemeler:** yüklü sürüm, Şimdi denetle, Şimdi güncelle, otomatik güncellemeler.

Değişiklikler anında uygulanır.

## 4. Güncellemeler

Yeni sürümler simülatörü kapattığınızda kendiliğinden kurulur, asla uçuş sırasında değil. Güncelleme yapıldığında bir bildirim sizi haberdar eder. Bunu Ayarlar'dan kapatabilirsiniz.

## 5. Sorun mu var?

- Bildirim alanındaki simgeye sağ tıklayın → **Sorun bildir…**. Kullanıcı adınız ve bilgisayar adınız gizlenmiş, önceden doldurulmuş bir GitHub issue açılır. Siz göndermediğiniz sürece hiçbir şey gönderilmez.
