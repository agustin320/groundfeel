# Groundfeel — Panduan cepat

[English](en.md)

Getaran realistis untuk joystick dan throttle WinWing (WINCTRL) URSA MINOR 32 di Microsoft Flight Simulator 2024. Gratis dan open source.

## 1. Pemasangan

1. Unduh `VibracionURSA-Setup.exe` dari [rilis terbaru](https://github.com/agustin320/vibracion-ursa/releases/latest).
2. Jalankan. Program terpasang hanya untuk pengguna Anda, tanpa hak administrator.
3. Jika Windows SmartScreen mengatakan penerbitnya tidak dikenal, klik **Info selengkapnya → Tetap jalankan**. Program ini belum memiliki tanda tangan digital.
4. Biarkan **Mulai bersama Windows** tetap dicentang. Program akan menunggu di area notifikasi sampai Anda membuka simulator.

## 2. Penggunaan pertama

1. Di **SimAppPro**, matikan getaran untuk joystick dan throttle. Jika tidak, kedua program akan berebut motor.
2. Buka simulator. Ikon di area notifikasi (di samping jam) menampilkan **titik hijau** saat terhubung, **abu-abu** saat menunggu, dan **oranye** saat dijeda.

## 3. Pengaturan

Klik kanan ikon di area notifikasi → **Pengaturan**:

- **Status:** koneksi ke simulator, perangkat yang ditemukan, dan apa yang sedang bergetar saat ini.
- **Intensitas:** kekuatan getaran joystick, throttle, dan taxi di darat.
- **Opsi:** joystick hanya bergetar di darat, jeda, mulai bersama Windows, bahasa.
- **Pembaruan:** versi terpasang, "Periksa sekarang", "Perbarui sekarang", pembaruan otomatis.

Perubahan langsung berlaku.

## 4. Pembaruan

Versi baru terpasang dengan sendirinya saat Anda menutup simulator, tidak pernah di tengah penerbangan. Sebuah notifikasi memberi tahu Anda saat pembaruan selesai. Anda bisa mematikannya di Pengaturan.

## 5. Ada masalah?

- Klik kanan ikon di area notifikasi → **Laporkan masalah…**. Ini membuka issue GitHub yang sudah terisi, dengan nama pengguna dan nama komputer Anda disamarkan. Tidak ada yang dikirim kecuali Anda sendiri yang mengirimkannya.

Tanpa telemetri dan tanpa data pribadi. Satu-satunya koneksi internet adalah ke GitHub untuk memeriksa dan mengunduh pembaruan, dan Anda bisa mematikannya di Pengaturan.
