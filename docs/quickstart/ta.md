# Groundfeel — விரைவுத் தொடக்கம்

[English](en.md)

Microsoft Flight Simulator 2024 இல் WinWing (WINCTRL) URSA MINOR 32 ஜாய்ஸ்டிக் மற்றும் த்ராட்டிலுக்கு யதார்த்தமான அதிர்வு. இலவசம், திறந்த மூலம்.

## 1. நிறுவுதல்

1. [சமீபத்திய வெளியீட்டிலிருந்து](https://github.com/agustin320/vibracion-ursa/releases/latest) `VibracionURSA-Setup.exe` ஐப் பதிவிறக்கவும்.
2. அதை இயக்கவும். நிர்வாகி உரிமைகள் இல்லாமல், உங்கள் பயனருக்கு மட்டும் நிறுவப்படும்.
3. வெளியீட்டாளர் தெரியவில்லை என்று Windows SmartScreen சொன்னால், மேலும் தகவல், பிறகு எப்படியும் இயக்கு என்பதைக் கிளிக் செய்யவும் (**More info → Run anyway**). இந்த நிரலுக்கு இன்னும் குறியீட்டுக் கையொப்பம் இல்லை.
4. **Windows உடன் தொடங்கு** தேர்வைக் குறித்தபடியே வைத்திருங்கள். நீங்கள் சிமுலேட்டரைத் திறக்கும் வரை இது அறிவிப்புப் பகுதியில் காத்திருக்கும்.

## 2. முதல் பயன்பாடு

1. **SimAppPro** இல் ஜாய்ஸ்டிக் மற்றும் த்ராட்டிலுக்கான அதிர்வை அணைக்கவும். இல்லையெனில் இரண்டு நிரல்களும் மோட்டார்களுக்காகப் போட்டியிடும்.
2. சிமுலேட்டரைத் திறக்கவும். அறிவிப்புப் பகுதியில் உள்ள ஐகான் (கடிகாரத்தின் அருகில்) இணைந்திருக்கும்போது **பச்சைப் புள்ளி**, காத்திருக்கும்போது **சாம்பல்**, இடைநிறுத்தப்பட்டிருக்கும்போது **ஆரஞ்சு** நிறத்தைக் காட்டும்.

## 3. அமைப்புகள்

ஐகானில் வலது கிளிக் செய்யவும் → **அமைப்புகள்**:

- **நிலை:** சிமுலேட்டர் இணைப்பு, கண்டறியப்பட்ட சாதனங்கள், இப்போது எது அதிர்கிறது.
- **தீவிரம்:** ஜாய்ஸ்டிக், த்ராட்டில் மற்றும் தரை ஓட்ட அதிர்வின் வலிமை.
- **விருப்பங்கள்:** ஜாய்ஸ்டிக் தரையில் மட்டும், இடைநிறுத்தம், Windows உடன் தொடங்குதல், மொழி.
- **புதுப்பிப்புகள்:** நிறுவப்பட்ட பதிப்பு, இப்போது சரிபார், இப்போது புதுப்பி, தானியங்கு புதுப்பிப்புகள்.

மாற்றங்கள் உடனடியாகப் பொருந்தும்.

## 4. புதுப்பிப்புகள்

நீங்கள் சிமுலேட்டரை மூடும்போது புதிய பதிப்புகள் தாமாகவே நிறுவப்படும்; பறக்கும்போது ஒருபோதும் இல்லை. புதுப்பிக்கப்பட்டதும் ஒரு அறிவிப்பு உங்களுக்குத் தெரிவிக்கும். இதை அமைப்புகளில் அணைக்கலாம்.

## 5. சிக்கல்களா?

- ஐகானில் வலது கிளிக் செய்யவும் → **சிக்கலைப் புகாரளி…**. உங்கள் பயனர் பெயரும் கணினிப் பெயரும் மறைக்கப்பட்ட, முன்பே நிரப்பப்பட்ட GitHub issue திறக்கும். நீங்கள் சமர்ப்பிக்காத வரை எதுவும் அனுப்பப்படாது.
- முழு வழிகாட்டி: [English](../USER_GUIDE.md) · [Español](../GUIA_DE_USUARIO.md)
