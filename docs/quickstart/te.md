# URSA Rumble — త్వరిత ప్రారంభం

[English](en.md)

Microsoft Flight Simulator 2024లో WinWing (WINCTRL) URSA MINOR 32 జాయ్‌స్టిక్ మరియు థ్రాటిల్ కోసం వాస్తవిక కంపనం. ఉచితం, ఓపెన్ సోర్స్.

## 1. ఇన్‌స్టాల్ చేయడం

1. [తాజా రిలీజ్](https://github.com/agustin320/vibracion-ursa/releases/latest) నుండి `VibracionURSA-Setup.exe` డౌన్‌లోడ్ చేయండి.
2. దాన్ని రన్ చేయండి. ఇది అడ్మిన్ హక్కులు లేకుండా మీ యూజర్‌కు మాత్రమే ఇన్‌స్టాల్ అవుతుంది.
3. ప్రచురణకర్త తెలియదని Windows SmartScreen చెబితే, మరింత సమాచారం, ఆపై ఏదేమైనా రన్ చేయి నొక్కండి (**More info → Run anyway**). ఈ ప్రోగ్రామ్‌కు ఇంకా కోడ్ సంతకం లేదు.
4. **Windowsతో ప్రారంభించండి** ఎంపికను టిక్ చేసి ఉంచండి. మీరు సిమ్యులేటర్ తెరిచే వరకు ఇది నోటిఫికేషన్ ఏరియాలో వేచి ఉంటుంది.

## 2. మొదటి ఉపయోగం

1. **SimAppPro**లో జాయ్‌స్టిక్ మరియు థ్రాటిల్ కంపనాన్ని ఆఫ్ చేయండి. లేకపోతే రెండు ప్రోగ్రామ్‌లు మోటార్ల కోసం పోటీపడతాయి.
2. సిమ్యులేటర్ తెరవండి. నోటిఫికేషన్ ఏరియాలోని ఐకాన్ (గడియారం పక్కన) కనెక్ట్ అయినప్పుడు **ఆకుపచ్చ చుక్క**, వేచి ఉన్నప్పుడు **బూడిద రంగు**, పాజ్ చేసినప్పుడు **నారింజ రంగు** చూపిస్తుంది.

## 3. సెట్టింగ్‌లు

ఐకాన్‌పై రైట్-క్లిక్ చేయండి → **సెట్టింగ్‌లు**:

- **స్థితి:** సిమ్యులేటర్ కనెక్షన్, కనుగొన్న పరికరాలు, ప్రస్తుతం ఏది కంపిస్తోంది.
- **తీవ్రత:** జాయ్‌స్టిక్, థ్రాటిల్ మరియు గ్రౌండ్ రోల్ కంపన బలం.
- **ఎంపికలు:** జాయ్‌స్టిక్ నేలపై మాత్రమే, పాజ్, Windowsతో ప్రారంభం, భాష.
- **అప్‌డేట్‌లు:** ఇన్‌స్టాల్ చేసిన వెర్షన్, ఇప్పుడే తనిఖీ చేయండి, ఇప్పుడే అప్‌డేట్ చేయండి, ఆటోమేటిక్ అప్‌డేట్‌లు.

మార్పులు వెంటనే అమలవుతాయి.

## 4. అప్‌డేట్‌లు

కొత్త వెర్షన్‌లు మీరు సిమ్యులేటర్ మూసివేసినప్పుడు వాటంతట అవే ఇన్‌స్టాల్ అవుతాయి, విమానం నడుపుతున్న మధ్యలో ఎప్పుడూ కాదు. అప్‌డేట్ అయినప్పుడు ఒక నోటిఫికేషన్ మీకు తెలియజేస్తుంది. దీన్ని సెట్టింగ్‌లలో ఆఫ్ చేయవచ్చు.

- ఐకాన్‌పై రైట్-క్లిక్ చేయండి → **సమస్యను నివేదించండి…**. మీ యూజర్ పేరు మరియు కంప్యూటర్ పేరు దాచబడిన, ముందే నింపిన GitHub issue తెరుచుకుంటుంది. మీరు సమర్పించకపోతే ఏదీ పంపబడదు.
