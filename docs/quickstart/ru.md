# URSA Rumble — Быстрый старт

[English](en.md)

Реалистичная вибрация для джойстика и РУДа WinWing (WINCTRL) URSA MINOR 32 в Microsoft Flight Simulator 2024. Бесплатно и с открытым исходным кодом.

## 1. Установка

1. Скачайте `VibracionURSA-Setup.exe` со страницы [последнего релиза](https://github.com/agustin320/vibracion-ursa/releases/latest).
2. Запустите его. Программа устанавливается только для вашего пользователя, права администратора не нужны.
3. Если Windows SmartScreen сообщает, что издатель неизвестен, нажмите **Подробнее → Выполнить в любом случае**. У программы пока нет цифровой подписи.
4. Оставьте включённым пункт **Запускать вместе с Windows**. Программа будет ждать в области уведомлений, пока вы не запустите симулятор.

## 2. Первый запуск

1. В **SimAppPro** отключите вибрацию для джойстика и РУДа. Иначе обе программы будут бороться за моторы.
2. Запустите симулятор. Значок в области уведомлений (рядом с часами) показывает **зелёную точку**, когда есть подключение, **серую** — во время ожидания и **оранжевую** — на паузе.

## 3. Настройки

Щёлкните правой кнопкой по значку в области уведомлений → **Настройки**:

- **Состояние:** подключение к симулятору, найденные устройства и что вибрирует прямо сейчас.
- **Интенсивность:** сила вибрации джойстика, РУДа и руления.
- **Параметры:** вибрация джойстика только на земле, пауза, запуск вместе с Windows, язык.
- **Обновления:** установленная версия, «Проверить сейчас», «Обновить сейчас», автоматические обновления.

Изменения применяются сразу.

## 4. Обновления

Новые версии устанавливаются сами, когда вы закрываете симулятор, и никогда — посреди полёта. Об обновлении вам сообщит уведомление. Это можно отключить в настройках.

## 5. Проблемы?

- Щёлкните правой кнопкой по значку в области уведомлений → **Сообщить о проблеме…**. Откроется заполненный issue на GitHub, в котором имя пользователя и имя компьютера скрыты. Ничего не отправляется, пока вы сами его не отправите.
- Полное руководство: [English](../USER_GUIDE.md) · [Español](../GUIA_DE_USUARIO.md)

## Конфиденциальность

Никакой телеметрии и никаких персональных данных. Единственное подключение к интернету — к GitHub, чтобы проверять и скачивать обновления, и его можно отключить в настройках.
